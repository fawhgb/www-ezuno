FAQ

No connection if Alfresco is behind a Reverse-Proxy?

With some Reverse Proxies the out of the box OpenCMIS configuration is not correct. In this case you have to override the settings directly in Alfresco’s alfresco-global.properties.

Steps to validate OpenCMIS configuration:

1. Open the URL of the atom binding https://alf.somehost.net/alfresco/api/-default-/public/cmis/versions/1.0/atom in your Browser, login with and Administrator account and open the XML returned.

2. Make sure that the content URLs in the XML file are correct. They should all start with https://alf.somehost.net/alfresco/api

3. If they are not correct you have to override the default settings in alfresco-global.properties

opencmis.context.override=true
opencmis.context.value=
opencmis.servletpath.override=true
opencmis.servletpath.value=
opencmis.server.override=true
opencmis.server.value=https://alf.somehost.net/alfresco/api

4. Update the tomcat connector configuration as well

<Connector ... URIEncoding="UTF-8" proxyName="alf.somehost.net" proxyPort="443" scheme="https" />

Window turns black when moved to a secondary screen in Microsoft Windows?

This is related to delegation of buffering to DirectDraw and/or Direct3D in Java.

To solve this problem add the following (system-wide) environment variable to Microsoft Windows:

J2D_D3D=false

How can I change ezuno settings for all users?

Create or upload a settings file

You can change all ezuno settings for all users by creating a settings file in Alfresco at

/ezuno/ezuno-settings.properties

next to where you placed the ezuno license.

You can find an example for this settings file here: ezuno-settings.properties

ezuno will look for new settings on startup and then every few minutes. If new settings are available, ezuno will prompt the user to either apply the settings now or later or for a restart depending on the configuration.

# when the settings should be applied
setting.config.time=2017-01-01T00:00
# true if a restart is necessary or 
# false if the user is allowed to work 
# with the current settings till next restart
setting.config.restart=false

Apply settings only for some users

If you want to apply the new settings only to some users you can do this by removing the read permissions of this file for all other users.

Use the Microsoft Windows Registry

It is also possible rollout changed setting in the Microsoft Windows Registry. Please contact ezuno support for an example.
